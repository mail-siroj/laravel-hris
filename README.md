# Laravel HRIS

A modern Human Resource Information System (HRIS) built with Laravel 12, Filament, Livewire, and MySQL.

## Features

- Employee Management
- Attendance Tracking
- Leave Management
- Overtime Requests
- Payroll Management
- Performance Evaluation
- Department & Position Management
- Role & Permission Management
- Reports & Analytics Dashboard
- Export to Excel and PDF

## Tech Stack

- Laravel 12
- PHP 8.4
- Filament v4
- Livewire
- MySQL
- Tailwind CSS
- Spatie Permission
- Laravel Excel
